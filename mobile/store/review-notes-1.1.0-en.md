Mualim Hub (مركز المعلم) is a productivity tool for school teachers in Saudi Arabia (Arabic interface): teaching portfolio, appreciation certificates, student follow-up sheets, and now a weekly class timetable. It is the companion app of https://mualimhub.com and uses the same account.

DEMO ACCOUNT: credentials are in the Sign-In Information fields (PDF export is enabled for it). You can also create a new account from the login screen.

NEW IN 1.1.0
- Tab جدولي (My schedule): the teacher's weekly timetable, view and edit only. Tap any slot to add a class (class, subject, school). The gear button (أوقات الحصص والتنبيه) sets period times, school days, and an optional reminder 5/10/15 minutes before each class.
- Reminders are local notifications scheduled on the device (no push server, no tracking). The app asks for notification permission only when the teacher turns the reminder on.
- Swipe a file card left to delete it (a confirmation is shown).

MAIN FEATURES
- ملفاتي: create and edit portfolios, add evidence from Photos, Camera or Files (each item gets a QR code), preview, download PDF.
- الشهادات: certificates with live preview. الكشوف: follow-up sheets and grade entry.
- حسابي: profile, password, log out, and حذف الحساب (Delete account).

All content is private to the teacher who created it; there is no feed, messaging or way to see other users' content, so reporting/blocking does not apply. The app has no purchases, prices or links to buy anything. It uses only our own server (mualimhub.com); no third-party analytics, ads, AI or payment services. It works the same in all regions.
