# ملف إنجاز المعلم

منصة ويب (تعمل أيضًا كتطبيق على الجوال PWA) تتيح للمعلم:

1. التسجيل والدخول مجانًا: المعلم ينشئ ملفاته ويعدّلها ويرفع شواهده ويعاينها بدون دفع. **تنزيل ملف PDF النهائي فقط يحتاج اشتراكًا** (شهري / سنوي)، والمعاينة لغير المشترك عليها علامة مائية ولا تُطبع من المتصفح.
2. **إنشاء ملف جديد** يفتح مشروعًا جاهزًا بجميع صفحات ملف الإنجاز بعناوينها.
3. تعديل المحتوى بحرية: نصوص منسقة، حقول، جداول، صور، روابط مع **رمز QR تلقائي**، اقتباسات.
   - **رفع ملفات الشواهد مباشرة** (PDF، Word، Excel، PowerPoint، صور، MP4): يُحفظ الملف على الموقع برابط عام عشوائي `/f/<رمز>` ويُولَّد له رمز QR يفتحه من أي جوال.
   - **عدة ملفات على نفس البند ونفس رمز QR** (حتى 20 ملفًا): الرمز يفتح صفحة `/b/<رمز>` فيها قائمة ملفات البند، أو الملف مباشرة إن كان واحدًا. الرمز ثابت لا يتغير عند إضافة ملفات أو حذفها.
   - صور المعرض تأخذ الشكل الزخرفي للصفحة، والضغط عليها (في المعاينة أو الـPDF) يفتحها كاملة عبر رابط عام عشوائي `/i/<رمز>`.
4. إضافة صفحات أو حذفها أو تكرارها أو إعادة ترتيبها.
5. **حفظ تلقائي** والرجوع للملف في أي وقت.
6. **تصدير PDF** بتصميم دفتر (صفحتين متقابلتين) أو صفحة A4 مفردة، مع فهرس مرقّم تلقائيًا وروابط قابلة للنقر.
7. خمسة أنماط ألوان (نعناعي، وردي، كحلي، رملي، بنفسجي).
8. **لوحة إدارة** (`/admin`): بحث عن المعلمين بالاسم أو البريد أو الجوال، تمديد الاشتراك أو تحديد تاريخ انتهائه أو إلغاؤه، إعادة تعيين كلمة المرور، إيقاف الحساب أو حذفه، سجل المدفوعات، تعديل الأسعار، **أكواد الخصم** (نسبة أو مبلغ ثابت، لخطة معينة أو للكل، حد استخدام وتاريخ انتهاء، وخصم 100% يفعّل الاشتراك مجانًا)، ورسوم بيانية للتسجيلات والاشتراكات والإيرادات يوميًا وشهريًا.

## التشغيل

يتطلب Node.js 22.5 أو أحدث.

```bash
npm install
npm start            # http://localhost:3000
```

لتصدير PDF تحتاج متصفح Chromium. إذا لم يكن موجودًا:

```bash
npx playwright install chromium
# أو حدّد مسارًا موجودًا:
CHROMIUM_PATH=/path/to/chrome npm start
```

## النشر المجاني (Oracle Cloud) — بأمر واحد

خادم Oracle المجاني دائمًا + رابط مجاني من sslip.io + شهادة HTTPS مجانية.

1. أنشئ خادم Ubuntu 24.04 (Ampere A1، 2 معالج و12GB ذاكرة) وافتح المنفذين 80 و443 في Security List.
2. ادخل على الخادم وشغّل:
   ```bash
   git clone https://github.com/aalmershed/Teacher.git injaz && cd injaz && bash setup.sh
   ```
   السكربت يسألك عن بريدك ومفتاحي ميسر، ثم يثبّت Docker ويفتح المنافذ ويشغّل الموقع.
3. **التحديث تلقائي:** السكربت يضيف مهمة تتحقق من GitHub كل 5 دقائق، وتحدّث الموقع عند وجود تعديلات جديدة (`auto-update.sh`، والسجل في `/var/log/injaz-update.log`). للتحديث الفوري يدويًا: `cd injaz && bash update.sh`

## النشر بضغطة زر (Render) (مدفوع)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/aalmershed/Teacher)

1. اضغط الزر أعلاه، وسجّل في Render بحساب GitHub نفسه، واسمح له بالوصول لمستودع Teacher.
2. يطلب منك Render ثلاث قيم:
   - `ADMIN_EMAIL`: بريدك (تسجّل به في الموقع لتصبح مديرًا).
   - `MOYASAR_PUBLISHABLE_KEY`: المفتاح العام من لوحة ميسر (`pk_live_...`).
   - `MOYASAR_SECRET_KEY`: المفتاح السري من لوحة ميسر (`sk_live_...`).
3. اضغط **Apply** وأدخل بطاقة الدفع لـ Render (خطة Starter مع قرص 5GB ≈ 8 دولار شهريًا).
4. بعد 5–10 دقائق يعمل الموقع على رابط مثل `https://teacher-portfolio.onrender.com`. افتحه وسجّل ببريد المدير.

**ربط دومين خاص لاحقًا:** في Render ← الخدمة ← Settings ← Custom Domains أضف الدومين واتبع التعليمات، ثم أضف متغير `PUBLIC_URL=https://دومينك`.

**إشعارات ميسر (اختياري ومستحسن):** في Render ← Environment انسخ قيمة `MOYASAR_WEBHOOK_SECRET`، ثم في لوحة ميسر ← Webhooks أضف الرابط `https://رابط-موقعك/payments/moyasar/webhook` والصق القيمة في Secret Token واختر `payment_paid`.

## النشر على الإنترنت (خادم VPS + دومين)

جُرّبت هذه الطريقة كاملة داخل حاوية Docker: التسجيل، إنشاء ملف، رفع شاهد، تصدير PDF، وبقاء البيانات بعد إعادة التشغيل.

**المطلوب:**
- **دومين** (مثل `injaz.sa`) من أي مسجّل نطاقات.
- **خادم VPS** بنظام Ubuntu 24.04، ذاكرة **2GB على الأقل** (تصدير PDF يشغّل متصفحًا). أي مزوّد يصلح: Hetzner، DigitalOcean، Vultr، أو مزوّد سعودي.

**الخطوات:**

1. في إعدادات الدومين أضف سجل **A** يشير إلى عنوان IP الخادم (للدومين نفسه، و`www` إن أردت).
2. ادخل على الخادم وثبّت Docker:
   ```bash
   ssh root@IP-الخادم
   curl -fsSL https://get.docker.com | sh
   ```
3. انسخ المشروع وجهّز الإعدادات:
   ```bash
   git clone https://github.com/aalmershed/Teacher.git injaz && cd injaz
   cp .env.example .env
   nano .env        # عدّل DOMAIN و PUBLIC_URL و ADMIN_EMAIL
   ```
4. شغّل الموقع:
   ```bash
   docker compose up -d --build
   ```
   خلال دقيقة يصدر Caddy شهادة HTTPS تلقائيًا ويعمل الموقع على `https://الدومين`.
5. افتح الموقع وسجّل حسابًا بنفس البريد الذي وضعته في `ADMIN_EMAIL` لتصبح مديرًا، ثم افتح `/admin`.

**الدفع عبر ميسر:**
1. من لوحة ميسر ← الإعدادات ← مفاتيح API: انسخ المفتاح العام (`pk_live_...`) والسري (`sk_live_...`) إلى `.env` في `MOYASAR_PUBLISHABLE_KEY` و`MOYASAR_SECRET_KEY`. المفتاح السري لا يُشارك مع أحد ولا يُرفع على GitHub.
2. اكتب نصًا عشوائيًا طويلًا في `MOYASAR_WEBHOOK_SECRET`، ثم في لوحة ميسر ← Webhooks أضف الرابط `https://دومينك/payments/moyasar/webhook` بنفس النص كـ Secret Token واختر حدث `payment_paid`. هذا يضمن تفعيل الاشتراك حتى لو أغلق المعلم الصفحة قبل الرجوع للموقع.
3. أعد التشغيل: `docker compose up -d`.

كيف يعمل: المعلم يختار الخطة ويدفع في نموذج ميسر (مدى، فيزا، ماستركارد). بعد الدفع يتحقق الخادم من العملية **مباشرة من ميسر بالمفتاح السري** (الحالة مدفوعة، المبلغ مطابق للخطة، العملة ريال، ولم تُستخدم من قبل) ثم يفعّل الاشتراك. لإضافة STC Pay أو Apple Pay: `MOYASAR_METHODS=creditcard,stcpay,applepay` (Apple Pay يحتاج توثيق الدومين في لوحة ميسر).

بديل بدون بوابة: `PAYMENT_PROVIDER=manual` — المعلم يطلب التفعيل وأنت تفعّل اشتراكه من لوحة الإدارة.

**التحديث بعد أي تعديل على الكود:**
```bash
cd injaz && git pull && docker compose up -d --build
```

**النسخ الاحتياطي:** كل البيانات (الحسابات، الملفات، الصور، الشواهد) في مجلد `data/`. انسخه دوريًا:
```bash
tar czf backup-$(date +%F).tar.gz data
```

## الإعدادات (متغيرات البيئة)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `3000` | منفذ الخادم |
| `ADMIN_EMAIL` | — | البريد الذي يصبح مديرًا عند تسجيله (يفتح `/admin`، ومنها يُعدّل اسم المعلم إن احتاج تصحيح) |
| `PRICE_MONTHLY` | `29` | سعر الاشتراك الشهري (ر.س) |
| `PRICE_YEARLY` | `199` | سعر الاشتراك السنوي (ر.س) |
| `TRIAL_DAYS` | `0` | أيام تنزيل مجانية للمسجلين الجدد (0 = لا يوجد؛ التنزيل للمشتركين فقط) |
| `PAYMENT_PROVIDER` | `mock` | `moyasar` = بوابة ميسر. `manual` = التفعيل يدوي من لوحة الإدارة. `mock` = يفعّل بدون دفع (للتطوير فقط) |
| `MOYASAR_PUBLISHABLE_KEY` / `MOYASAR_SECRET_KEY` | — | مفاتيح ميسر (العام للنموذج، السري للتحقق من الدفع من الخادم) |
| `MOYASAR_WEBHOOK_SECRET` | — | كلمة سر إشعارات ميسر (Webhook) |
| `MOYASAR_METHODS` | `creditcard` | طرق الدفع: `creditcard`، `stcpay`، `applepay` |
| `DATA_DIR` | `./data` | مكان قاعدة البيانات والصور وملفات الشواهد المرفوعة |
| `BRAND_NAME` | `ملف إنجاز المعلم` | اسم المنصة على الغلاف الخلفي |
| `PUBLIC_URL` | — | رابط الموقع الحقيقي (مثل `https://injaz.sa`). **مهم**: تُبنى عليه روابط ملفات الشواهد ورموز QR في الـPDF. بدونه يُستخدم عنوان الطلب الحالي |
| `TRUST_PROXY` | — | اضبطه على `1` إذا كان الموقع خلف Nginx أو Cloudflare |
| `FILE_MAX_MB` | `25` | الحد الأقصى لحجم ملف الشاهد |
| `STORAGE_QUOTA_MB` | `1000` | المساحة الكلية لكل معلم |
| `NODE_ENV` | — | اضبطه على `production` عند النشر (كوكيز آمنة) |

## هيكل المشروع

```
server/
  index.js      الخادم وجميع واجهات API
  db.js         قاعدة البيانات (SQLite المدمجة في Node)
  template.js   ← قالب صفحات ملف الإنجاز (عدّل هنا لتغيير الصفحات الافتراضية)
  render.js     تحويل الملف إلى HTML للطباعة + أنماط الألوان والتصميم
  pdf.js        تصدير PDF عبر Chromium
  payments.js   الاشتراكات والدفع (مكان ربط بوابة الدفع)
public/
  index.html    الصفحة الرئيسية التعريفية
  auth.html     الدخول / التسجيل
  app.html      لوحة "ملفاتي"
  editor.html   المحرر  (+ assets/js/editor.js)
  subscribe.html صفحة الاشتراك
  admin.html    لوحة الإدارة (المستخدمون، الاشتراكات، تفعيل يدوي)
```

## صفحات القالب

مبنية على هيكل "ملف الإنجاز 1448":
الغلاف، البسملة، الفهرس، المقدمة، أهداف برنامج صعوبات التعلم، طرق تدريس صعوبات التعلم، الرؤية، الرسالة والقيم، السيرة الذاتية، رؤية المملكة في التعليم، أخلاقيات المهنة، الأهداف العامة والخاصة، الأهداف الخاصة لمادة لغتي، الجدول الدراسي، توزيع المنهج والمسرد والتحضير، الخطط الأسبوعية، الاستراتيجيات والوسائل التعليمية، المبادرات والأنشطة، سجل المتابعة وأوراق العمل، النمو المهني والمجتمعات المهنية، الاختبارات، تحليل نتائج الاختبارات، الخطط العلاجية، الخطط الإثرائية، أعمال الطالبات المميزة، متابعة وتحفيز الطالبات، الخاتمة، الغلاف الخلفي.
