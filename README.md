# إنجاز — منصة ملف إنجاز المعلم

منصة ويب (تعمل أيضًا كتطبيق على الجوال PWA) تتيح للمعلم:

1. التسجيل والدخول، مع اشتراك عضوية مدفوع (شهري / سنوي) وفترة تجريبية.
2. **إنشاء ملف جديد** يفتح مشروعًا جاهزًا بجميع صفحات ملف الإنجاز بعناوينها.
3. تعديل المحتوى بحرية: نصوص منسقة، حقول، جداول، صور، روابط مع **رمز QR تلقائي**، اقتباسات.
   - **رفع ملفات الشواهد مباشرة** (PDF، Word، Excel، PowerPoint، صور، MP4): يُحفظ الملف على الموقع برابط عام عشوائي `/f/<رمز>` ويُولَّد له رمز QR يفتحه من أي جوال.
4. إضافة صفحات أو حذفها أو تكرارها أو إعادة ترتيبها.
5. **حفظ تلقائي** والرجوع للملف في أي وقت.
6. **تصدير PDF** بتصميم دفتر (صفحتين متقابلتين) أو صفحة A4 مفردة، مع فهرس مرقّم تلقائيًا وروابط قابلة للنقر.
7. خمسة أنماط ألوان (نعناعي، وردي، كحلي، رملي، بنفسجي).

## التشغيل

يتطلب Node.js 22.5 أو أحدث.

```bash
npm install
npm start            # http://localhost:3000
```

لتصدير PDF تحتاج متصفح Chromium. إذا لم يكن موجودًا:

```bash
npx playwright install chromium
# أو حدّد مسارًا موجودًا:
CHROMIUM_PATH=/path/to/chrome npm start
```

## الإعدادات (متغيرات البيئة)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `3000` | منفذ الخادم |
| `ADMIN_EMAIL` | — | البريد الذي يصبح مديرًا عند تسجيله (يفتح `/admin`، ومنها يُعدّل اسم المعلم إن احتاج تصحيح) |
| `PRICE_MONTHLY` | `29` | سعر الاشتراك الشهري (ر.س) |
| `PRICE_YEARLY` | `199` | سعر الاشتراك السنوي (ر.س) |
| `TRIAL_DAYS` | `7` | أيام الفترة التجريبية (0 لإلغائها) |
| `PAYMENT_PROVIDER` | `mock` | بوابة الدفع. `mock` يفعّل الاشتراك مباشرة بدون دفع (للتجربة) |
| `DATA_DIR` | `./data` | مكان قاعدة البيانات والصور وملفات الشواهد المرفوعة |
| `BRAND_NAME` | `إنجاز` | اسم المنصة على الغلاف الخلفي |
| `PUBLIC_URL` | — | رابط الموقع الحقيقي (مثل `https://injaz.sa`). **مهم**: تُبنى عليه روابط ملفات الشواهد ورموز QR في الـPDF. بدونه يُستخدم عنوان الطلب الحالي |
| `TRUST_PROXY` | — | اضبطه على `1` إذا كان الموقع خلف Nginx أو Cloudflare |
| `FILE_MAX_MB` | `25` | الحد الأقصى لحجم ملف الشاهد |
| `STORAGE_QUOTA_MB` | `1000` | المساحة الكلية لكل معلم |
| `NODE_ENV` | — | اضبطه على `production` عند النشر (كوكيز آمنة) |

## هيكل المشروع

```
server/
  index.js      الخادم وجميع واجهات API
  db.js         قاعدة البيانات (SQLite المدمجة في Node)
  template.js   ← قالب صفحات ملف الإنجاز (عدّل هنا لتغيير الصفحات الافتراضية)
  render.js     تحويل الملف إلى HTML للطباعة + أنماط الألوان والتصميم
  pdf.js        تصدير PDF عبر Chromium
  payments.js   الاشتراكات والدفع (مكان ربط بوابة الدفع)
public/
  index.html    الصفحة الرئيسية التعريفية
  auth.html     الدخول / التسجيل
  app.html      لوحة "ملفاتي"
  editor.html   المحرر  (+ assets/js/editor.js)
  subscribe.html صفحة الاشتراك
  admin.html    لوحة الإدارة (المستخدمون، الاشتراكات، تفعيل يدوي)
```

## صفحات القالب

مبنية على هيكل "ملف الإنجاز 1448":
الغلاف، البسملة، الفهرس، المقدمة، أهداف برنامج صعوبات التعلم، طرق تدريس صعوبات التعلم، الرؤية، الرسالة والقيم، السيرة الذاتية، رؤية المملكة في التعليم، أخلاقيات المهنة، الأهداف العامة والخاصة، الأهداف الخاصة لمادة لغتي، الجدول الدراسي، توزيع المنهج والمسرد والتحضير، الخطط الأسبوعية، الاستراتيجيات والوسائل التعليمية، المبادرات والأنشطة، سجل المتابعة وأوراق العمل، النمو المهني والمجتمعات المهنية، الاختبارات، تحليل نتائج الاختبارات، الخطط العلاجية، الخطط الإثرائية، أعمال الطالبات المميزة، متابعة وتحفيز الطالبات، الخاتمة، الغلاف الخلفي.
